# 사내 HR 챗봇 - 요구사항 정의서 (연습용)

## 배경
HR팀에 반복적으로 들어오는 정책 문의(연차, 재택근무, 경비 등)를 챗봇이 1차 응대하여
HR 담당자의 반복 업무를 줄인다.

## 목표 (MVP 범위)
- 사내 정책 문서 기반으로 질문에 답변 (RAG)
- 문서에 없는 내용은 "모른다"고 답하고 담당자 연결 안내 (Hallucination 방지)
- 웹 브라우저에서 접속 가능한 간단한 챗 UI 제공

## 범위 밖 (MVP에서는 안 함)
- 실제 사번/개인정보 조회 연동
- 다국어 지원
- 모바일 앱

## 성공 기준
- 정책 문서에 있는 질문에 대해 정확한 답변
- 문서에 없는 질문에 대해 거짓 답변(hallucination) 하지 않음

## 사용 스택
- LLM: OpenAI API (gpt-4o-mini)
- 벡터DB: Chroma
- 백엔드: FastAPI
- 프론트: Streamlit (내부 데모용)
